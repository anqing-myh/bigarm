# V1：初版代码（localhost）

完成大臂游戏的本地可运行版本，沿用仔仔的深绿配色和环形战场，支持 2–10 人进入同一服务进行回合对战。

## 已加入的招式

共实现 **57 个行动选项**：

- **6 个基础动作**：大臂、攒、方盾、圆盾、闪、超闪。
- **32 个攻击招式**：拳、踹、ber、刀、海浪、火炬、海啸、火轮、万箭齐发、小海波、镖、小火轮、地震、三连踹、太阳拳、连环拳、青龙剑、刀点刀、镰刀、六拳合一、回旋镖、冲天炮、冲天钻、青龙偃月刀、凤鸣九天、凤之烈焰、凤之长星、流星锤、少林棍、剑、天翻地覆、均衡之刃。
- **11 种盾与生产器**：泡沫盾、幽灵盾、闪电盾、雷电盾、海神盾、烈焰盾、雷达，以及大臂、攒攒、方盾、圆盾生产器。
- **8 个法术及辅助招式**：小电、凤之守护、幽灵闪、连环闪、虚无闪、雷闪、回一滴血、防六拳合一。

本版不包含锤、锤锤锤、打断、幽灵回旋镖；太阳拳和三连踹保留，但没有反弹效果。回旋镖按不同点数的单体攻击处理，可以被虚无闪防住。

## 已完成的模块

| 模块 | 完成内容 |
| --- | --- |
| 招式与装备目录 | 集中维护资源、成本、点数、属性、防法、盾类别及特殊效果。 |
| 独立判定引擎 | 与界面、房间和网络分离；完成行动校验、互攻压制、攻击排序、多段与范围伤害、盾交互、治疗、死亡和胜负判定。 |
| 中途选择与持续效果 | 支持选盾、小电移盾、祝福减伤、必要弃置；可保存并继续结算，不重复扣费。支持持续攻击、持续防御和死亡后的效果清理。 |
| 房间与联机服务 | 临时身份、创建和加入房间、准备、秘密选招、同时揭晓、倒计时、断线处理、重新开局和胜场统计。 |
| 网页界面 | 登录页、大厅、环形战场、目标与方向选择、资源和装备查看、招式手册、战况记录及手机布局。 |
| 启动与部署入口 | 提供 Windows 启动脚本、默认 3200 端口、本地预览、临时公网隧道入口和 Docker 配置。 |

## 验证与当前范围

- 通过 **27 项规则及服务集成测试**。
- 通过桌面、手机和十人布局的浏览器回归，覆盖真实选招、攻击、造盾、刷新后续结、邀请及胜场流程。
