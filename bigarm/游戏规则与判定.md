## 2. 对局与状态模型

### 2.1 对局基本规则

1. 当前模式为各自为战。规则不限定固定人数；首版可容纳 2～10 人，未来组队不应要求重写所有目标关系。
2. 每名玩家初始生命 `H=5`、生命上限 `Hmax=5`。六种基础资源、祝福值、盾和持续效果初始均为空或 0。
3. 生命上限是玩家的独立状态。当前没有提高上限的招式，但不能把“上限永远等于 5”当作永久规则。
4. 每回合，回合开始时仍存活的玩家各选择恰好一个行动，同时揭晓。不能主动跳过，也不能同时选择多个新行动。
5. 所有本回合效果完成后才在回合末判定死亡。中间生命可以为负，不提前取消已发出的攻击、治疗、造盾、资源收益或效果施加。
6. 回合末生命 `H≤0` 的玩家死亡；当前没有濒死和复活。最后一名存活者获胜，同时全灭为平局；没有其他获胜条件和回合数上限。
7. 生命、资源、盾及层数、已有持续效果、历史出招均公开；本回合行动在同时揭晓前保密。
8. 暂时没有进入空中的手段，但保留对空标记和空中状态的语义。不能因为当前无法起飞而删掉相关招式规则。

来源：A01～A07、C02～C03、E06。

### 2.2 概念状态

这些是判定所需的信息，不是网络消息格式，也不是具体代码字段约定。

| 对象 | 必须能表达的信息 |
| --- | --- |
| 对局 | 回合号、固定座位及座位顺序、回合开始时存活者、各玩家状态、本回合行动、结算记录、胜负结果。 |
| 玩家 | 生命与生命上限；六种资源库存；祝福值；每个持有盾；持续攻击与防御；最近基础动作历史；存活状态；预留空中和阵营关系。 |
| 行动 | 唯一行动编号、使用者、招式、成本及是否已支付、合法目标；顺序群攻所选方向；固有部分、独立法术、攻击批次及命中后效果。 |
| 一段攻击 | 原使用者、当前来源及目标、所属招式、段号、点数、伤害量、物理/法术属性、伤害等级、对空、穿盾/无视盾规则、反弹记录和是否被取消。 |
| 持续效果 | 来源招式和使用者、目标、开始及到期回合、原始点数、效果类型；重复施放形成的各份效果分别记录。 |
| 盾实例 | 类型、等级、位置、当前盾位、剩余层数、免疫条件、数量限制分组、能否被小电移除；同名的两面盾也须能分别识别。 |
| 选择请求 | 所属阶段、事件编号、作选择的玩家、当前合法选项和选择结果。小电和承伤盾在事件发生时选择，祝福减伤在伤害汇总后选择，超限弃置在判死后选择。 |

生命上限、伤害/控制等级、盾交互类型均保留扩展能力。尚未加入的招式“打断”不纳入目录；这不等于删掉已明确的锤和锤锤锤效果。

## 3. 资源与基础动作

### 3.1 名称、库存与点数

| 代号 | 中文名 | 每单位点数 | 基础动作收益 |
| --- | --- | ---: | --- |
| B | 大臂 | 1 | 获得 1 B |
| Z | 攒 | 0.8 | 获得 1 Z |
| F | 方盾 | 1.5 | 获得 1 F |
| Y | 圆盾 | 2 | 获得 1 Y |
| S | 闪 | 2.5 | 获得 1 S |
| C | 超闪 | 3.5 | 获得 1 C |
| 祝福值 | 祝福值 | 4.5 | 没有对应的免费基础动作；当前仅由凤鸣九天产生。 |

资源库存与祝福值没有上限，不设过期；不能交换或以别种资源替代成本。资源数量与点数不同：1 个攒仍是 1 个资源，其攻击点数贡献为 0.8。

成本写法 `BBF=2B+F`、`3F=FFF`。非例外攻击的基础点数为：

`P = nB + 0.8nZ + 1.5nF + 2nY + 2.5nS + 3.5nC + 4.5n祝福`

踹、单目标地震、特殊克制、回旋镖途中加点等按专门规则处理。均衡之刃中“攒视为 0.5”只改变其伤害，不改变攒通常的点数。

### 3.2 基础动作不是攻击

- 选择基础动作免费获得对应资源，并具有该字母在攻击表“防法”中规定的防御效果。基础动作 B 不等于消耗 B 使用“拳”，基础动作 F 也不等于持有“泡沫盾”。
- 基础动作提供的是当回合防御，不消耗库存资源，也不是一面需要打掉的持有盾。
- 组合攻击、法术或造盾只支付其成本，不自动获得成本中字母对应的基础防御。例如使用 `BZC` 的冲天炮，不因此获得 B、Z、C 的防御。
- 受伤、防御被穿透，甚至最终在本回合死亡，都不影响已经选定的基础动作正常获得资源。
- 同一防御效果通常可以防住本回合任意多次相符攻击和段数，不因防住一次消失。火轮的 S 只防第一段是明确例外。
- 生产器只修改对应基础动作的收益，总共获得 3 个，而不是额外获得 3 个；火轮命中的收益不触发生产器。
- 刚获得的资源立即入账，可供本回合后续机制使用，例如凤鸣九天的祝福值可以用于回合末减伤。按新增 U07，不再执行“全场先统一扣费再开始”的步骤；每个行动在激活时支付自己的成本并立即产生固有收益。仍然每人只有一个新行动，不能凭借本回合所得资源再选第二招。

来源：B01～B06、D08、K01～K03及此前基础动作确认。

### 3.3 闪与超闪的连续使用限制

只检查实际选择的基础动作，不检查招式成本，也不检查法术赋予的等效防御：

- 不允许连续两回合都选择 C。
- 不允许连续三回合都从 `{S,C}` 中选择。
- `S→C→S`、`S→S→C` 不合法；`C→F→C` 合法。
- `幽灵闪→C→幽灵闪` 合法。幽灵闪、连环闪、虚无闪持续生效时，也不自动产生基础动作 S/C 的使用记录。

来源：Excel A1、B03～B04。

### 3.4 祝福值的回合末减伤

除支付招式成本外，玩家可以自选花费祝福值减少自己当回合受到的伤害。按**每一次实际扣血的伤害事件**分别计算，不先合并整回合伤害：

设第 i 次可减伤事件原本造成 `d_i>0`，为其花费 `b_i` 个祝福值，则：

- `b_i` 必须为非负整数；总花费不能超过届时可用祝福值。
- 最终伤害 `d'_i=d_i-b_i`，且必须严格满足 `d'_i>0`。
- 不允许超额使用，也不允许把伤害降为 0；单次最多使用 `max(0, ceil(d_i)-1)` 个。
- 0.5 或 1 伤害均不能用祝福值减少；1.5 伤害最多花 1 点降至 0.5；2 伤害最多花 1 点降至 1。
- 没有祝福值时，不产生这项选择；有祝福值也可以全部选择花费 0。
- 已被防住、免疫或完全由盾抵挡的事件没有实际扣血伤害，不额外用祝福值。

流星锤自伤明确分成若干个独立的 0.5 伤害事件，每个都不能用整数祝福值减伤，不能合并后减伤。其他真伤默认仍适用同一整数规则，不额外发明真伤免减伤属性。减伤完成之后才判死，超限弃盾在判死之后，详见第 5 节。

来源：B05～B06。

## 4. 效果分类与目标

### 4.1 三类效果与两种法术触发方式

| 分类 | 判定意义 |
| --- | --- |
| 物理攻击 | 一种攻击属性；可被针对物理攻击的机制交互，例如锤。 |
| 法术攻击 | 另一种攻击属性；仍是攻击，仍比较互攻点数，不等于先于攻击结算的法术。 |
| 法术效果 | 与伤害属性分开，包括控制、治疗和部分增益；按独立法术或命中附带法术触发。 |

**独立法术**不依赖伤害命中，在攻击前进行判定。例如小电的移盾、凤鸣九天的祝福收益。凤鸣九天的攻击被压制或被防住，并不取消其独立收益；但该法效被锤锤锤取消则不获得祝福。

**命中附带法术**要求对应攻击先命中，随后立即触发。命中持有盾也满足条件；被免伤、基础防御挡住则不满足。火轮每段命中后的圆盾资源收益按命中触发处理。

攻击失效不自动表示整招所有部分失效。需要分别记录伤害、独立法术、命中附带法术、自身刚性防效、造盾和基础资源收益。各个机制的分类以第 5.9 节为准；暂定分类在 D01/Q01 明示，虚无闪范围口径在 D06/Q06。

来源：补充说明开头、C07、E03、G04、G08、G13。

### 4.2 目标集合

| 类型 | 目标规则 |
| --- | --- |
| 单体攻击 | 必须指定一名其他存活玩家，不能指定自己或空目标。 |
| 双目标攻击 | 地震指定 1 或 2 名不同的其他存活玩家；单目标和双目标有不同点数。 |
| 群攻 | 覆盖回合内相关的其他存活玩家集合，不包括施法者。 |
| 溅射 | 主目标加其左右各一名存活邻居；圆环首尾相接，跳过死者；去重，并排除施法者。每名目标单独判定。 |
| 顺序群攻 | 玩家选择顺时针或逆时针，依座位绕一圈，跳过死者，不攻击自己；从所选方向的第一名存活邻座开始，不另选首目标。 |
| 持续单体攻击 | 首次施放锁定目标，之后不能改目标；每回合按持续效果生成攻击。 |
| 法术 | 是否指定别人由具体招式决定；小电可指定别人，回一滴血只能作用自己。 |

尚未在回合末判死的玩家，不因中途生命降为 0 或负数提前从目标、邻居或顺序路径中移除。

### 4.3 空中与等级

每段攻击对每名目标分别检查对空能力。不能对空的攻击不能对空中目标造成伤害；但这不妨碍它先参与互攻点数比较。当前没有起飞动作，空中交互主要保留作未来扩展。

伤害和控制分别有等级，默认均为 1。当前没有明确列出的 2 级伤害；锤锤锤的控制为 2 级，其余已列法术效果默认 1 级。锤的抵消不再归为控制或法术，而是独立的物理攻击抵消规则，不受免控或禁法直接取消。

若伤害等级不高于免伤等级，则伤害被免疫；控制与免控同理。高等级完整穿透低等级防护，不按差值减弱。刚性免伤、免控在有效期内不限次数，并可保护玩家的盾和相关状态。针对具体盾类的“无视/穿透”仍需按专门交互处理，不能把所有防护合成一个布尔值。

`回合无敌 = 1 级免伤 + 1 级免控`，不等于不可被任何更高等级效果影响。

来源：D05～D07、E01～E08、K04。

## 5. 统一判定流程

### 5.1 效果不是整招的开关

把一个行动展开为以下组成部分；同一部分使用通用处理器，不根据招式名字另写完整结算函数：

| 组成部分 | 激活/触发时机 | 被锤锤锤禁法影响 |
| --- | --- | --- |
| 成本与材料 | 本行动激活一次时支付 | 不退款，不重复支付。 |
| 固有效果 | 激活时登记，包括基础收益、造盾、合成、刚性防效、攻击的持续发生器 | 不取消。 |
| 独立法术 | 攻击前，按等级控制图判定 | 可以取消，按法术实例处理。 |
| 攻击批次 | 进入攻击队列；一批可包含多段和多目标 | 伤害本身不因禁法消失。 |
| 命中后法术 | 对应一段攻击命中后立即尝试 | 可以取消；即使还没生成，也要受当回合禁法标记限制。 |
| 普通命中回调 | 对应命中后执行，不自带控制属性 | 不取消；必须显式分类，不能把所有回调都归为法术。 |

**整理采用的分类口径（D01，待 Q01 统一确认）**：Excel 的“法效”栏为法术，刚性防效栏为固有防护；基础收益、造盾和持续攻击的建立按固有部分处理。用户明确的例外优先于栏目：锤抵消明确不是法术；凤鸣祝福明确是法术收益。火轮收益在法效栏，暂定为命中后 1 级法术收益，与普通基础动作收益区分。此处分类是可实现的暂定表，不声称所有栏目已经被用户逐项确认。

### 5.2 整回合状态机

| 阶段 | 输入和动作 | 离开阶段的条件 |
| --- | --- | --- |
| R0 行动快照 | 保存回合开始存活者、座位、旧持续效果；验证每人一个新行动、材料和目标。只做可用性检查，不执行全场统一扣费。 | 所有新行动合法。 |
| R1 激活行动 | 各行动只激活一次，在自己的激活步骤支付成本，立即登记其固有部分、造盾、基础收益和法术/攻击模板。保留法效被取消也不退款的规则。 | 所有行动已展开；未开始执行独立法术。 |
| R2 独立法术 | 先 2 级控制图，再 1 级控制图；执行成功的治疗、收益、持续防御建立、反弹登记和小电等。 | 图中效果均已生效、失效或因环而取消。 |
| R3 攻击准备 | 由模板和旧持续攻击生成全部攻击意图、明确的目标集合及相互压制结果；建立可执行批次的优先队列。 | 攻击和依赖关系均建立。 |
| R4 逐次攻击 | 从可执行批次中按优先级取一个，完成其内部段序和各目标判定；必要时立刻暂停要求小电以外的承伤选盾；立即处理命中回调，再释放后继批次。 | 队列和当前批次均为空。 |
| R5 祝福减伤 | 展示本回合实际生命伤害事件，每名有祝福值的玩家分配整数减伤。 | 所有分配满足逐次伤害严格大于 0 与资源总量约束。 |
| R6 最终生命与死亡 | 应用伤害账本及有效治疗；本阶段才标记死亡。 | 每名玩家最终生命和存活性确定。 |
| R7 持有量整理 | 对仍存活且持有物超限的玩家，要求弃置到所有上限均满足。已经死亡的玩家不再需要为后续回合整理装备。 | 所有相关持有量合法。 |
| R8 回合结束 | 输出结果、判胜或平局；若继续则到期旧效果、推进回合号并开放下一次行动。 | 一次结算只提交一次。 |

**已确认的更改**：小电在自己成功生效时立即询问移除对象，不延迟到回合末；所有攻击之前假定盾仍存在，只有实际移除或消耗才删除。判死之后才处理容量超限的弃盾。新增 U07 取代旧“全场先统一支付”的文字。

**拟定的最小补齐**：R1 按座位激活，但所有激活完成才开始 R2，避免座位决定能否看见当回合新盾；承伤选盾在命中时发生，不做整回合分支重演（D04）；在 R6 使用具体治疗上限口径 D07。均在末尾列出确认点。

R1 的具体次序为：先从全场已揭晓行动识别“锤与锤锤锤互相指定”的整招相消关系，再逐行动支付成本、激活未被整招相消的组件。被整招相消者仍支付成本，但不登记抵消凭证、不向 R2 生成法效；D03 暂定也不向 R3 生成互攻意图。这样不能等到攻击阶段才回头撤销已经执行的 2 级禁法。

### 5.3 控制依赖图：按级别处理，失效节点不能再影响别人

对每个待发生的独立法术建立节点，至少记录 `效果编号、行动编号、发出者、目标、控制等级、效果种类、目标法效集合、状态`。法术攻击的伤害不放进图；锤抵消也不放进图。

**边的方向**：若 u 生效能够令 v 不能按原意生效，则连 `u→v`。最常见是锤锤锤禁法指向目标本回合的法术实例。自身免控等已经确立的固有事实先过滤不可能命中的控制，不能让一个必然被免控挡住的控制继续压住别的节点。

法术实例另记“自益/对外有害”语义。D01 暂定自己的治疗、获得祝福、建立防御等自益法术不会被自己的免控或反弹拒绝；它们仍是可被外部禁法取消的法术。免控及太阳拳反弹检查的是对外有害的控制投递。不能把“是法术”直接等同于“对自己也要触发免控”。

对 2 级图先执行以下循环，再用更新后的状态构建 1 级图：

1. 从尚未处理且入度为 0、其非取消先决条件也已完成的节点中选择一个；多个可选节点按座位、行动内效果序号、效果编号确定唯一顺序（D01）。
2. 在它真正尝试生效时检查免控与适用反弹；无效则标记无效并移除其节点及关联边，不应用它的禁用关系。
3. 若有效，应用该节点效果。若是禁法，取消它确实影响的未结算法术节点，并给相应玩家记录当回合禁法标记，阻止之后新生成的命中后法术。
4. 被取消节点及其边一起移除，**不执行它本来可能取消别人的效果**。已完成节点也移出未决图。继续寻找入度 0 节点。
5. 若仍有未决节点但没有可执行根节点，则所有剩余节点都不生效，结束本级图。包含依赖于环的尾部节点，不只取消强连通环本身；当前目录不存在单独由非取消先决条件形成的环。
6. 2 级成功施加的禁法直接排除受影响的 1 级节点，再进入 1 级图；不在同一张图内用 1 级控制倒过来推翻已完成的 2 级控制。

这与“按拓扑序把所有控制都执行一遍”不同。例如 A 禁 B，B 禁 C：A 成功后 B 被取消，B 就不能再禁 C，C 会解除依赖并获得执行机会。若 A、B 互禁且 B 还禁 C，无其他入度 0 节点，则 A、B、C 全部不生效。

**非取消的先决关系**单独存放，不能伪装成禁用边。具体是：给“反弹安装→需要读取该反弹的法术投递”建立先决关系，安装节点被取消或成功后均释放等待，前者继续投递而没有反弹。当前目录 1 级没有禁法，所以通过了 2 级禁法筛选的反弹安装都是可执行根；若将来增加同级禁法，必须等安装节点自身解除禁用依赖，不能强行抢先安装（D01）。反弹只重定向当次效果，产生带相同效果身份和反弹次数的返回投递，不复制整招。若返回后遇到第二次反弹则消失。若返回的控制会影响尚未处理节点，更新其依赖；不得回滚已经完成的高等级图。当前目录的等级 2 禁法与等级 1 新反弹跨级关系，以及返回效果的归属，按末尾 Q01/Q05 的暂定口径处理。

### 5.4 攻击意图、排序与分批

攻击有三个身份，不能只用一个数组边删除边判：

- **行动身份**：目标本回合选择了什么，供火炬和均衡之刃等读取；被压制不改变行动身份。
- **攻击意图**：该招本来指定哪些目标、每段用多少点数。用于互攻，保留到回合结束，不因伤害已经结算、被盾挡住、点数压制或锤抵消就删除。
- **待执行批次**：本次还需实际判定的攻击和回调，可能被取消，但不因此抹掉攻击意图。

普通优先键为 `点数降序、使用者座位升序、同一来源的发出序号升序、稳定批次编号升序`。特殊克制只改变互攻结果，不改变排序点数。攻击无论是否被压制，都按原有位置到达投递步骤，再判失效；不能因被压制而重排其他攻击。

**普通多段批次**：火轮、镰刀、万箭齐发各是一份连续批次。批次取得执行权后，先完成第一段对全部相关目标的判定，再完成第二段，中间不插入别人的同点数批次；每段仍分别互攻、消耗盾和触发命中回调。万箭的两轮不能合并伤害。

**顺序批次**：回旋镖类每经过一个目标是一份独立批次，从所选方向邻座开始。当前经过完成后才释放下一份，因此保留路径和幽灵回旋镖的前缀伤害；新释放的批次重新参与优先级竞争。普通回旋镖的每份点数按路径位置预先计算，第一份 3，第二份 4。仅对“已可执行”的批次按点数排序，这个依赖优先队列口径为 D02，需 Q02 确认；不能把全路径直接降序排序而先打最后一人。

一个普通群攻同段内的不同目标按座位处理，便于选择和日志可复现；它们的伤害仍按各自目标独立结算。方向性群攻按路径处理。旧持续攻击和本回合新攻击使用相同批次结构。

### 5.5 互攻只产生对该目标的失效标记

先冻结全部原始攻击意图（包括尚未可执行的顺序后继，但不包括 R1 已整招相消的锤/锤锤锤），对每一份甲→乙事件寻找乙→甲的各段意图，按普通点数或特殊克制比较。D03 暂定：存在一份能压制或等点抵消甲的反向意图，就标记甲这一份对乙失效；没有反向意图则不互攻。刀保底和 ber 克刀按第 6 节覆盖普通结果。

意图保留使结果不依赖谁先从队列弹出：一份已经判过、被锤抵消或不可能穿过对方防御的攻击，仍保留其明确应有的点数压制能力。只删除伤害效果，不删除声明。多份反向攻击的“存在即压制”口径、锤与锤锤锤整招抵消后是否仍保留意图列为 Q03；此规则不代替用户已经确认的各段完整点数。

### 5.6 锤：一次物理相消凭证

激活锤时登记一张一次性凭证：`持有人=锤使用者，允许来源=锤指定目标，类型=物理，剩余次数=1`。这是固有交互，不是法术，禁法和免控都不直接删除它。

按攻击顺序，找到指定目标对锤使用者投递的第一份物理伤害尝试；群攻也只看落到锤使用者这一份。凭证触发后：

- 这一份目标→锤使用者的物理伤害被取消；同段对其他玩家仍照常进行，后续物理段也保留。
- 锤本身的那份攻击失去伤害效果；若尚在队列中则到其原位置时记为失效。锤的点数压制仍保留。
- 一份凭证最多用一次；若目标只打法术攻击或没有对锤使用者出手，则不触发。

为避免“锤先打中，后面才说它被用于抵消”需要回滚，D03 暂定在 R3 已排序的原始投递上提前匹配凭证，双方的实际伤害都在投递前标记取消。按第 5.4 节先演算只含点数和依赖的调度顺序即可完成匹配，不需要预知选盾或实际伤害。多个锤凭证仍按同一稳定顺序消费；一份物理投递最多配一张凭证。被压制/免疫的物理尝试是否也消耗这张凭证，最后 Q03 明确询问；已确认的是锤自己的伤害被防住或压制不影响其抵消能力。

### 5.7 一次攻击的通用处理链

`到达原排序位置 → 检查已取消/互攻压制 → 对空 → 免疫 → 防法 → 反弹 → 命中 → 盾交互或记账扣血 → 命中后效果`

1. 攻击意图不会因为前面某份事件结算过就消失；无效原因写入日志。
2. 免疫包括等级免伤、范围免疫、元素盾和雷达。先按攻击的无视/穿透标签判断该盾能否参与免疫，不能先让“被无视的盾”挡住攻击。相应穿透优先口径见 D04/Q04。
3. 免疫优先于防法，防法优先于反弹。防法按持有的基础/等效防御匹配，火轮 S 仅第一段。
4. 真伤跳过普通承伤盾，不跳过互攻、对空、免伤和适用基础防法。刀的保底只覆盖普通互攻失效。
5. 第一次反弹把当前目标改为原来源，原目标不算命中；返回投递立即用同一链条检查目标防护。再次需要反弹时令效果消失。D05 默认不再参加互攻、不再触发锤凭证，且不重放群攻。
6. 穿过前面的阻止机制后标记 `命中=true`。盾完全挡伤仍是命中；没有可挡的盾才记录实际生命伤害。盾选择在该事件立即进行，只暂停此事件，不重新生成随机结果或重新扣成本。
7. 命中后立即生成对应回调；法术回调检查来源本回合禁法状态及目标免控/适用反弹，再生效。火轮的收益归原使用者还是返回后的来源按 D05/Q05。
8. 结果记录包括状态改变与原因，不能仅返回一个总伤害数。后续事件读取更新后的盾、空中和持续状态。

### 5.8 伤害、治疗、祝福与回合结束

R4 不即时判死，把每次实际扣血写成独立账本项：`事件编号、来源或无来源、目标、原伤害、伤害属性/等级、是否真伤、已分配祝福、最终伤害`。已由盾完全抵挡的命中仅记入事件日志，不伪造一个可减伤的生命伤害。

R5 按第 3.4 节分配祝福，流星锤每份 0.5 自伤各自保留。D07 暂定治疗在 R2 成功时立即受当前生命上限截顶，随后生命账本继续承受伤害，即：`治疗后生命=min(上限，治疗前生命+有效治疗量)`；R6 再扣除最终伤害并判死。以 5 血、治疗 1、受伤 2 为例，此口径最终为 3，不是 4，见 Q07。

判死后处理仍存活者的装备超限，再定胜负。容量整理不会复活死者，也不追溯改变已经完成的免疫和挡伤；整回合选择不做任意分支重演。无存活者平局，一名存活者获胜，其他情况推进回合；局已结束就不再让旧持续攻击额外打出下一回合。

## 6. 互攻、点数与特殊克制

### 6.1 普通互攻

只要甲的某段攻击指定乙、乙的某段攻击也指定甲，就比较攻击点数。指定包含直接目标、群攻覆盖、溅射覆盖和持续攻击，不要求双方都手动点击了对方。

- `P甲>P乙`：乙对甲的对应攻击失效。
- `P甲<P乙`：甲对乙的对应攻击失效。
- `P甲=P乙`：双方对应攻击互相抵消。

结果只作用于这对攻击者之间，不全局取消群攻。普通多段攻击每段都使用整招完整点数，逐段比较；持续攻击使用最初施放的完整点数。未命中不触发命中附带法术，独立法术不因此失效。

攻击即使后来会被基础防御、免疫或空中状态挡住，仍先参与点数比较。不能先删去被防住的攻击，再让它失去反击能力。

来源：D01～D05、I03。

## 7. 持有盾、生产器与雷达

### 7.1 盾的共同规则

- 盾是持续持有的实例，不是基础资源 F/Y，也不等于当回合选 F/Y 的防御。
- 能正常挡下伤害的盾，以**一次伤害事件**为单位抵挡。伤害再高也不溢出；火轮两次命中需要两次抵挡。
- 普通挡伤不能阻止控制；攻击打到盾上仍算命中，因此可以触发命中附带法术。真伤不能靠挡伤的盾抵挡，但相关免疫仍有效。
- 盾有独立的等级、位置和盾位：等级决定穿透/无视关系，位置决定承伤优先级，盾位决定持有容量。三者不能混用。
- 位置数越小越先承受攻击。同位置由玩家逐次选择，不要求提前给出固定排序。小电移盾已明确立即选择；普通承伤选盾采用同样的事件即时选择机制（D04），不与判死后的超限弃盾混为一谈。
- 每名存活者回合整理后持有盾位总和不超过 5；同名盾至多 2 个，生产器同名至多 1 个；四种元素盾合计至多 2 个；四种生产器合计至多 2 个。死亡者在 D08 中不再要求作无后续用途的弃置选择。
- 允许本回合暂时超限，回合末通过弃置恢复限制；不能在平时任意主动丢盾。回合末在死亡判定之后满足全部上限；拟定只允许为修正超限而作必要弃置，见 D08/Q08。
- 新造盾或合成盾在当回合攻击前就可使用。合成幽灵盾是一个完整行动，必须消耗两面真实泡沫盾，不能用受损幽灵盾或其他材料替代。

### 8.2 附加规则、盾交互与自身防护

**ber、刀、刀点刀。** 按第 6.2 节处理特殊互攻。刀的保底包括普通同点数抵消，但不是无条件必中。刀点刀的“无视点数”仅指特殊互攻胜负关系，不表示忽略免伤、盾或锤的取消；名义点数 7.5 仍用于排序，特殊胜负不改排序数值（新增 U05）。

**火炬。** 只检查目标当回合是否选择基础动作 F。持有泡沫盾、方盾生产器或成本含 F 都不会单独触发 2 伤害。

**海啸。** 穿泡沫级盾；对幽灵盾触发穿泡级攻击掉两层的特例。

**火轮。** 两段各独立判定，每段完整点数都是 4。每命中一段，使用者获得 1 Y；打掉盾或造成生命伤害都算命中，被免伤、免疫或防住不算。S 防御只挡第一段，第二段仍需检查其他防护；Y/C 防御可挡两段。生产器不放大命中所得 Y。

**万箭齐发、镰刀。** 明确保留段序。万箭先对各目标进行第一轮，再进行第二轮；不能合并为一次 1.5 伤害。镰刀也不能合并为一次 1 伤害。两段之间的盾、命中附带效果等变化要保留。

**地震。** 双目标时每名目标各承受一次 1 伤害，点数 7.5。只选一名目标时只造成一次 1 伤害，点数 15；不能重复选择同一人叠成 2 伤害。穿泡沫级、闪电级盾和雷达。

**锤。** 按新增 U03，只有其指定目标对锤使用者投递的第一次物理攻击可被抵消，群攻仅取消打到锤使用者这一份。触发后锤自身也失去攻击伤害，但点数压制保留；如果没有对应反向物理攻击，锤仍有其原本 1 伤害。锤的伤害被防住或压制不取消其抵消能力。该机制不是法术或控制，不用控制等级；按第 5.6 节的凭证处理，只有尚未明确的触发边界列入 Q03。

**三连踹。** 使用者当回合反弹来自非本招攻击目标的伤害，按第 5.3 节的顺序和次数限制处理。效果属于本回合反弹能力，不要求先伤害自己的攻击目标。

**太阳拳。** 穿泡沫级盾；使用者当回合反弹来自非本招攻击目标的控制。其伤害是法术攻击，控制反弹不是伤害属性。反弹能力作为独立法术登记，其安装受禁法影响；按第 5.3 节与 D01 处理。

**锤锤锤。** 对目标取消当回合法术效果，控制等级为 2；不取消法术攻击的伤害，不取消以前回合已施加的持续效果。新施放的治疗算本回合法术，会失效；造盾和资源收益一般保留，但凤鸣九天的祝福收益被明确分类为法术，会被取消。与锤互相指定时，双方整招抵消。其他法效及刚性防效按第 5.9 节分类；取消效果只对法术组件生效。

**六拳合一。** 使用者当回合获得 1 级免伤和 1 级免控。攻击无视泡沫级盾和雷达；基础动作均不能防，必须依靠“防六拳合一”或其他适用机制。适当等级的免伤有效；匹配成本的元素盾免疫也可能有效，例如海神盾可匹配成本中的 F。无视泡级与幽灵盾的关系采用 D04，并在 Q04 确认。

**回旋镖。** 可选顺时针或逆时针；第一名目标点数 3，第二名 4，以此类推。经过玩家就加点，不要求先造成伤害；被防住、压制或反弹也不终止后续路径。从所选方向邻座开始；动态排序采用第 5.4 节的依赖优先队列 D02。

**冲天炮、冲天钻。** 按第 10 节持续攻击规则。攻击表未列额外穿盾、自身免伤或控制。

### 9.1 小电与法效取消

小电的移盾是法术/控制，可以被免控、太阳拳反弹、锤锤锤取消；取消仍不退 CC。移盾发生在攻击前，所以不能先让已被移除的盾免疫后续攻击。

回一滴血只作用自己，不因别人的太阳拳直接反弹；被禁法则没有治疗效果。防六拳合一也属于当回合普通法术。幽灵闪等在本回合新施加的法术，与此前已经存在的同类防御必须区分；锤锤锤完全不影响旧效果。

当回合法术部分可以被取消，不把所有固有效果一起删除。按第 5.9 节分类，小电的 2 级免伤、雷闪/凤之守护的 2 级免疫以及攻击招式的刚性防效在 R1 登记；新持续闪避则作为法术，可能无法建立。分类采用 D01，并由 Q01 统一确认。

### 9.2 多份闪避效果

重复施放分别保留，不把所有持续时间合并成一个数字。一个回合可同时具有 S 和 C 的等效防御，任意适用防法都可阻止攻击；这些法术防御不获得基础资源，也不计入基础动作连续使用限制。

### 9.3 虚无闪的免疫范围

已明确免疫：单体多段、集中单目标地震、凤之烈焰主目标；按 J04 的补充表述，溅射和双目标伤害也归入“除群伤外可免疫”的范围。攻击反弹和持续单伤原则上仍按对应攻击类型判断。

**顺序群攻的原始资料仍冲突**：Excel 写“免疫单伤和顺序群伤”，J04 又称“回旋镖类型也算群伤”。为提供确定的暂定规则，D06 采用较新 J04 的范围分类：不免疫普通群攻和顺序群攻，免疫单体、双目标及溅射；范围标签保留到每次投递，而不是因拆成单目标事件就自动变成单伤。此处需 Q06 确认，不能当作原始资料已无冲突。虚无闪当回合自带 C 防法与范围免疫是不同效果，不能因范围免疫存在就省略防法。

## 10. 持续攻击与顺序效果

### 10.1 持续攻击

若在第 t 回合施放，持续 N 回合包含 t，即作用于 `t, t+1, …, t+N−1`：

| 招式 | 付费次数 | N | 每回合攻击 | 固定点数 |
| --- | ---: | ---: | --- | ---: |
| 冲天炮 | 1 | 3 | 对原目标 1 物理伤害 | 5.3 |
| 冲天钻 | 1 | 4 | 对原目标 0.5 物理伤害 | 4.3 |
| 凤之长星 | 1 | 5 | 对原目标 1 法术伤害，穿闪电级盾 | 9 |

- 首次施放后不再重复支付成本，目标不可更换；每回合正常参与互攻比较。
- 施法者每回合仍可选择一个新行动，旧持续攻击与新攻击一起生效；重复施放可以分别保留各份效果。
- 本回合被防住、被取消或被禁法，不自动删除未来回合的持续攻击。旧效果不因当回合锤锤锤而永久清除。
- 施法者之后死亡也不取消已经建立的持续效果；补充 I04 的“依然进行”保留效果存在性。目标已经死亡则该份效果保留至自然到期但空转，不生成打尸体的攻击，也不参与互攻；局终不再生成后续回合（D09，见 Q09）。不能自行改打其他人。
- 一次反弹只返回当回合那份攻击，不把未来各回合永久改向原施法者。

### 10.2 顺序群攻状态

回旋镖第 k 位被经过者面对 `P_k=3+(k−1)`，伤害固定 1。幽灵回旋镖点数固定 12.5，第 k 位面对：

`d_k = 1 + 0.5 × 此前以基础防法防住的玩家数`

命中盾不属于基础防法防住。两种回旋镖都不因某名玩家挡住或压制而中断路径。路径从邻座开始，按第 5.4 节逐次释放后继批次；分别记录每名目标面对的实际点数/伤害。D02 在 Q02 确认。

来源：H01～H04、I01～I05。

## 13. 可据此实现的判定契约

### 13.1 精确数值、标识和状态

- 当前资源库存与祝福值均为非负整数。攻击点数按十分之一为整数单位：B=10、Z=8、F=15、Y=20、S=25、C=35、祝福=45，踹=60，地震集中=150；比较不用浮点容差。
- 当前生命及伤害最小单位为 0.5，可用半点整数保存；祝福值每花 1 个对应减少 2 个半点单位。资源点数和生命单位不可混用。若未来加入其他分母，统一扩展精度，而不是在某个招式里混入浮点近似。
- 玩家、行动、法术实例、攻击意图、批次、一次投递、盾实例、持续实例和选择请求均有独立稳定编号。同一回合恢复执行时编号不变。
- 固定座位顺序用于同点数排序；方向和邻居只在当前回合开始存活者中计算。中途负血不改变这个集合。
- 每个新行动保存支付标记，材料合成保留所消耗盾的实例编号，持续效果生成保存原始成本和点数。同一回合不会因为恢复、反弹或下一段攻击再次付费。

### 13.2 招式定义需要的数据，而不是 35 套结算器

例如回旋镖只需要“方向链、初始点数 3、每跳加 1、伤害 1”的参数；幽灵回旋镖用同一个方向链，替换为“固定点数 12.5、基础防法阻挡后后缀伤害加 0.5、固有免疫 1”。两者不各自拥有一套防御算法。

### 13.3 提交、暂停和继续

判定器的概念输入为 `当前对局快照、每名存活者的新行动、已经作出的选择`。概念输出只能是以下之一，不预设 HTTP 或其他网络协议：

| 结果 | 内容和保证 |
| --- | --- |
| 行动不合法 | 给出玩家、行动、原因；未提交任何本回合改变。 |
| 需要选择 | 保存阶段、图/队列游标、相关实例、已完成事件和日志；给出选择者与当前合法选项。未生成后续攻击的假定结果。 |
| 回合完成 | 给出新状态、完整有序事件日志、各次伤害账本、被取消效果及原因、下一回合或对局结束结果。 |

选择只有三类：小电移除一件候选持有物、命中时选择最低可承伤位置中的盾、末尾分配祝福/超限弃置。无候选时按规则直接继续；唯一候选可直接选中，不改变规则结果。

恢复时只继续当前未完成的步骤。已支付成本、已发放资源、已移除的盾和已经触发的命中收益不可再次应用。选择失去合法性时不能静默选另一个对象，应拒绝该选择并返回当前合法选项；现阶段不引入超时或自动代选规则。

日志需要区分 `被压制、特殊克制、被锤抵消、免疫、防住、首次反弹、再次反弹消失、命中盾、穿盾、无视盾、实际伤害、命中法术被禁、控制环失效、治疗截顶、死亡、弃置`，从而能从日志重建结果。日志顺序不是新的游戏优先级，真实优先级由阶段与队列定义。

### 13.4 盾的统一路由（拟定约定 D04）

本节补足现有资料未完全闭合的穿透行为，供 Q04 确认。它是一套通用算法，不按每个攻击名字另写盾逻辑。

1. 先计算本攻击对每件盾的交互类型：普通、无视、穿透或幽灵层穿透。无视的盾不提供本次免疫，也不进入本次承伤候选；穿透的盾不提供本次匹配免疫，但仍保留被摧毁的候选身份。
2. 尚能参与免疫的元素盾/雷达，任意一个匹配则整次投递免疫，所有盾都不消耗。免伤或基础防法已经阻止的事件也不进入路由。
3. 真伤直接记生命伤害，所有普通承伤盾保留；这不取消第 2 步仍适用的免疫。
4. 普通伤害从当前最低位置的可交互盾中由玩家选一件。无候选则全额记录伤害。
5. 普通交互：普通单层盾消失并完全挡住本次；幽灵盾掉一层并完全挡住本次，即使掉至 0 也不溢出。
6. 穿透单层盾：盾消失，本次伤害未被阻挡，继续第 4 步。穿泡级遇幽灵盾：扣 `min(2,剩余层数)`，若仍有层则挡住本次；若已无层则继续第 4 步。沿途可能连续摧毁多件盾，最后仍无能挡的盾才扣血。
7. 无视泡级暂定包含幽灵盾的所有泡沫层；穿泡级仍使用上一项专门的两层扣除。这用类别匹配和每层穿透参数表达，不要求把所有盾类别排成全序。
8. 每次状态变化后重读当前实例列表；一份攻击最多消耗当前确实存在的有限盾实例，不会选到同一面已经摧毁的盾。命中只记一次，不因为穿过两面盾就重复发放火轮收益。

穿透/无视被列出的类别优先于该类别自身免疫，是为避免“地震明写穿闪级却永远先被闪电盾匹配 S 免疫”而采用的 D04。普通免伤等级和不在该类别内的其他盾免疫依旧有效。

### 13.6 持续实例与回合边界的精确定义

施放回合为 t、持续 N 回合的实例记录 `start=t, end=t+N−1`，仅当 `start≤当前回合≤end` 时有效。R8 准备进入下一回合时删除已到期实例；当前回合已经参与判定的效果不会因维护期限被追溯撤销。

新施放持续攻击只建立一份发生器，R3 统一从所有有效发生器中各生成一次当回合投递；不能又生成一次即时攻击，造成首回合打两次。每个实例记最后生成投递的回合，暂停恢复时同回合不再生成第二份。重复施放是不同编号的实例，不能误去重合并。

幽灵闪保留 t 和 t+1 的 C 防法；连环闪保留 t 至 t+2 的 S 防法。虚无闪拆成“仅 t 的 C 防法”和“t 至 t+2 的范围免疫”两份组件，共享原行动编号但各有期限；不能让当回合 C 防法错误持续三回合。刚性回合防护、反弹安装、禁法标记和锤凭证在回合结束后清空。基础动作的最近历史不清空，用于下一回合检查连续限制。

D09 中死亡来源保留稳定身份及尚未到期的发生器。它没有下一回合的新行动，也不因此给其他攻击凭空增加能指定死者的合法目标；其旧发生器对活目标仍正常投递。目标死亡的持续实例空转但继续经过回合计数，到期正常删除。局终直接停止回合推进，新局全部重置为第 2 节初始状态。

## 14. 需要你回答的剩余问题

新增 U01～U08 已落实，下面不再重复询问它们已经明确的部分。为让这份文档能够直接指导实现，每个剩余问题都附了具体暂定答案；你可以按 Q 编号写“同意 Dxx”，或只改其中不同的子项。问题的排序按对整个引擎的影响程度，不按招式数量。

1. **Q01：法术分类和控制图口径是否采用 D01？** 请重点核对第 5.9 节：刚性防效为固有，新的三种持续闪避、反弹安装、火轮命中收益为法术，持续攻击建立为固有；自益法术不被自己的免控/反弹挡住。控制图按“能使对方无法生效”连边；新 1 级太阳拳反弹晚于 2 级禁法，因此不能反弹本回合先结算的 2 级禁法。同级先安装未被禁的反弹，独立根按座位。上述哪些需要改动？
2. **Q02：回旋镖排序是否采用 D02 的依赖优先队列？** 例如邻座面对 3 点、第二人 4 点，但 4 点必须等经过邻座后才进入队列，而不是把整条路径展开后先结算 4 点；万箭等普通两段则在拿到执行权后连续完成两轮。若你要整条回旋镖直接按各次点数降序，需要另定“经过顺序”含义。
3. **Q03：互攻和锤剩下的边界是否采用 D03？** 多份反向攻击中任意一份足以压制当前段；被锤取消的伤害仍保留点数意图。锤指定目标打回来的第一份物理尝试即使已会被压制或免疫，也消耗这张凭证并取消锤伤害；互相指定的锤/锤锤锤整招抵消则连意图一起失效。是否有不同？
4. **Q04：承伤选盾与穿透是否采用 D04？** 承伤时即时选盾；穿透排除被穿类别的免疫，摧毁后继续打后盾/生命；三层幽灵被穿泡级打后剩一层并挡住本次，两层及以下被穿尽后继续；无视泡级也无视幽灵层。不采用其中某条时，请给出相应替代结果。
5. **Q05：反弹是否采用 D05？** 返回的这一份不再互攻、不再消耗锤凭证，但保留属性、防法、成本和范围；再次反弹消失；火轮这类命中收益仍归原使用者，而实际返回伤害的来源记反弹者。你希望改变哪一项？
6. **Q06：虚无闪是否采用 D06，明确不免疫回旋镖类？** 当前按较新 J04 将普通群攻和方向群攻都排除，将单体、双目标、溅射列为免疫；持续和反弹继承原范围。若仍要遵守 Excel 的“免疫顺序群伤”，只需明确改这一组标签。
7. **Q07：治疗是否按 D07 先截上限再受伤？** 5 血治疗 1、同回合受伤 2，文档暂定最后 3 血；不是先算净变化得到 4。
8. **Q08：超限弃盾是否采用 D08 的必要弃置？** 判死后存活者整理，全部上限同时满足；不能趁超限顺便多丢无关装备，判断标准是弃置集合去掉任何一项后都会不合法，而不要求全局弃件数最少。
9. **Q09：持续效果遇到死亡是否采用 D09？** 来源死、目标活仍攻击；目标死保留效果但空转，不再生成攻击或互攻；整局结束不再额外结算下一回合。
10. **Q10：法术赋予的等效 S/C 防御是否按 D10 计入“被基础防法防住的人数”？** 文档暂定计入流星锤自伤和幽灵回旋镖加伤，但不计入实际选择基础动作的连续使用历史；如果先被免疫挡住，就不再算防法防住。
11. **Q11：小电是否按 D11 可以选自己？** 暂定可选任意存活者，以带成本法术自拆盾可以，免费主动丢盾仍不可以。
