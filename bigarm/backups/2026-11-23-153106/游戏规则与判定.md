# 大臂游戏规则与判定

本文是当前大臂规则版本的完整说明，用于实现游戏判定引擎，不涉及房间、联网、超时、断线或部署。规则目录、状态、事件、选择和结算均在本文定义，不依赖仔仔代码补足。

## 2. 对局与状态模型

### 2.1 对局基本规则

1. 当前模式为各自为战。规则不限定固定人数；首版可容纳 2～10 人，未来组队不应要求重写所有目标关系。
2. 每名玩家初始生命 `H=5`、生命上限 `Hmax=5`。六种基础资源、祝福值、盾和持续效果初始均为空或 0。
3. 生命上限是玩家的独立状态。当前没有提高上限的招式，但不能把“上限永远等于 5”当作永久规则。
4. 每回合，回合开始时仍存活的玩家各选择恰好一个行动，同时揭晓。不能主动跳过，也不能同时选择多个新行动。
5. 所有本回合效果完成后才在回合末判定死亡。中间生命可以为负，不提前取消已发出的攻击、治疗、造盾、资源收益或效果施加。
6. 回合末生命 `H≤0` 的玩家死亡；当前没有濒死和复活。最后一名存活者获胜，同时全灭为平局；没有其他获胜条件和回合数上限。
7. 生命、资源、盾及层数、已有持续效果、历史出招均公开；本回合行动在同时揭晓前保密。
8. 暂时没有进入空中的手段，但保留对空标记和空中状态的语义。不能因为当前无法起飞而删掉相关招式规则。

来源：A01～A07、C02～C03、E06。

### 2.2 概念状态

这些是判定所需的信息，不是网络消息格式，也不是具体代码字段约定。

| 对象 | 必须能表达的信息 |
| --- | --- |
| 对局 | 回合号、固定座位及座位顺序、回合开始时存活者、各玩家状态、本回合行动、结算记录、胜负结果。 |
| 玩家 | 生命与生命上限；六种资源库存；祝福值；每个持有盾；持续攻击与防御；最近基础动作历史；存活状态；预留空中和阵营关系。 |
| 行动 | 唯一行动编号、使用者、招式、成本及是否已支付、合法目标；回旋镖路径方向；固有部分、独立法术、攻击批次及命中后效果。 |
| 一段攻击 | 使用者及目标、所属招式、段号、点数、伤害量、物理/法术属性、伤害等级、对空、穿盾/无视盾规则和是否被取消。 |
| 持续效果 | 来源招式和使用者、目标、开始及到期回合、原始点数、效果类型；重复施放形成的各份效果分别记录。 |
| 盾实例 | 类型、等级、位置、当前盾位、剩余层数、免疫条件、数量限制分组、能否被小电移除；同名的两面盾也须能分别识别。 |
| 选择请求 | 所属阶段、事件编号、作选择的玩家、当前合法选项和选择结果。小电和承伤盾在事件发生时选择，祝福减伤在伤害汇总后选择，超限弃置在判死后选择。 |

生命上限、伤害/控制等级、盾交互类型均保留扩展能力。当前可选招式仅以第 8、9 节及基础动作目录为准。

## 3. 资源与基础动作

### 3.1 名称、库存与点数

| 代号 | 中文名 | 每单位点数 | 基础动作收益 |
| --- | --- | ---: | --- |
| B | 大臂 | 1 | 获得 1 B |
| Z | 攒 | 0.8 | 获得 1 Z |
| F | 方盾 | 1.5 | 获得 1 F |
| Y | 圆盾 | 2 | 获得 1 Y |
| S | 闪 | 2.5 | 获得 1 S |
| C | 超闪 | 3.5 | 获得 1 C |
| 祝福值 | 祝福值 | 4.5 | 没有对应的免费基础动作；当前仅由凤鸣九天产生。 |

资源库存与祝福值没有上限，不设过期；不能交换或以别种资源替代成本。资源数量与点数不同：1 个攒仍是 1 个资源，其攻击点数贡献为 0.8。

成本写法 `BBF=2B+F`、`3F=FFF`。非例外攻击的基础点数为：

`P = nB + 0.8nZ + 1.5nF + 2nY + 2.5nS + 3.5nC + 4.5n祝福`

踹、单目标地震、特殊克制、回旋镖途中加点等按专门规则处理。均衡之刃中“攒视为 0.5”只改变其伤害，不改变攒通常的点数。

### 3.2 基础动作不是攻击

- 选择基础动作免费获得对应资源，并具有该字母在攻击表“防法”中规定的防御效果。基础动作 B 不等于消耗 B 使用“拳”，基础动作 F 也不等于持有“泡沫盾”。
- 基础动作提供的是当回合防御，不消耗库存资源，也不是一面需要打掉的持有盾。
- 组合攻击、法术或造盾只支付其成本，不自动获得成本中字母对应的基础防御。例如使用 `BZC` 的冲天炮，不因此获得 B、Z、C 的防御。
- 受伤、防御被穿透，甚至最终在本回合死亡，都不影响已经选定的基础动作正常获得资源。
- 同一防御效果通常可以防住本回合任意多次相符攻击和段数，不因防住一次消失。火轮的 S 只防第一段是明确例外。
- 生产器只修改对应基础动作的收益，总共获得 3 个，而不是额外获得 3 个；火轮命中的收益不触发生产器。
- 刚获得的资源立即入账，可供本回合后续机制使用，例如凤鸣九天的祝福值可以用于回合末减伤。按新增 U07，不再执行“全场先统一扣费再开始”的步骤；每个行动在激活时支付自己的成本并立即产生固有收益。仍然每人只有一个新行动，不能凭借本回合所得资源再选第二招。

来源：B01～B06、D08、K01～K03及此前基础动作确认。

### 3.3 闪与超闪的连续使用限制

只检查实际选择的基础动作，不检查招式成本，也不检查法术赋予的等效防御：

- 不允许连续两回合都选择 C。
- 不允许连续三回合都从 `{S,C}` 中选择。
- `S→C→S`、`S→S→C` 不合法；`C→F→C` 合法。
- `幽灵闪→C→幽灵闪` 合法。幽灵闪、连环闪、虚无闪持续生效时，也不自动产生基础动作 S/C 的使用记录。

来源：Excel A1、B03～B04。

### 3.4 祝福值的回合末减伤

除支付招式成本外，玩家可以自选花费祝福值减少自己当回合受到的伤害。按**每一次实际扣血的伤害事件**分别计算，不先合并整回合伤害：

设第 i 次可减伤事件原本造成 `d_i>0`，为其花费 `b_i` 个祝福值，则：

- `b_i` 必须为非负整数；总花费不能超过届时可用祝福值。
- 最终伤害 `d'_i=d_i-b_i`，且必须严格满足 `d'_i>0`。
- 不允许超额使用，也不允许把伤害降为 0；单次最多使用 `max(0, ceil(d_i)-1)` 个。
- 0.5 或 1 伤害均不能用祝福值减少；1.5 伤害最多花 1 点降至 0.5；2 伤害最多花 1 点降至 1。
- 没有祝福值时，不产生这项选择；有祝福值也可以全部选择花费 0。
- 已被防住、免疫或完全由盾抵挡的事件没有实际扣血伤害，不额外用祝福值。

流星锤自伤明确分成若干个独立的 0.5 伤害事件，每个都不能用整数祝福值减伤，不能合并后减伤。其他真伤默认仍适用同一整数规则，不额外发明真伤免减伤属性。减伤完成之后才判死，超限弃盾在判死之后，详见第 5 节。

来源：B05～B06。

## 4. 效果分类、目标与等级

### 4.1 组件及触发

| 分类 | 意义与本版用途 |
| --- | --- |
| 物理攻击、法术攻击 | 两种攻击属性，均参加互攻比较。法术攻击不等于攻击前法术，也不自动跳过盾或防法。 |
| 固有效果 | 基础动作收益与防法、制造/合成、持有盾能力、刚性防护和持续攻击发生器。 |
| 独立法术 | 攻击前处理的治疗、防御建立、小电、凤鸣祝福等，不要求伤害命中。 |
| 命中附带效果 | 火轮每段命中获得 Y、天翻地覆命中打落；在该次命中后立即处理。 |

当前不存在取消法效的机制，**不能因保留了“法术”分类就继续执行旧禁法标记、依赖图或控制环算法**。分类仍用于阶段、免控和以后扩展。

打掉普通承伤盾也算命中，可以触发命中附带效果；被点数压制、免疫或基础防法阻止，不算命中。火轮收益是自益，不被自己的免控挡住；小电移盾、打落是有害控制，要检查受术者免控。法术收益和攻击分别判定，凤鸣攻击未命中不影响其 3 祝福值。

### 4.2 目标和范围

| 类型 | 规则 |
| --- | --- |
| 单体攻击 | 指定一名其他存活玩家，不能自己或空目标。 |
| 地震 | 指定 1 或 2 名不同的其他存活者；单目标点数 15、伤害 1，双目标点数 7.5、每人伤害 1。 |
| 群攻 | 覆盖其他存活者，不含自己；即使只剩一名对手，范围标签仍是群体。 |
| 溅射 | 主目标及其左右存活邻居，圆环首尾相接，跳过已死亡者；去重、排除使用者；每名目标独立判定。 |
| 回旋镖路径 | 选择顺/逆时针，从该方向存活邻座开始绕一圈，跳过已死亡者、不打自己；第 k 名目标得到点数 3+(k−1)、伤害 1 的独立单体投递。 |
| 持续攻击 | 锁定原目标，不可更换；包含施放回合，之后每回合生成一次单体投递。 |
| 法术 | 按具体招式的目标政策；小电可指定他人，能否自己采用 D11，治疗仅自己。 |

回合开始存活集合在整回合内固定；中途生命非正不提前移除目标、邻居或路径成员。范围标签不由投递拆成了几个对象决定：群攻拆开后仍是群体，回旋镖每份明确为单体。这使虚无闪对两者有不同结果。

### 4.3 等级和空中

伤害和控制等级默认 1；本版本没有列出的 2 级伤害或 2 级有害控制，但小电、雷闪和凤之守护的高等级防护保留。等级较高的伤害/控制完整穿透较低的免伤/免控；等级不高于对应防护则免疫。有效期内不限次数，免控也保护玩家持有物免受小电等控制。

自益治疗、收益、建立防御不被自身免控拒绝。`回合无敌=1级免伤+1级免控`是术语定义，不表示当前另有可选无敌招式。

当前没有起飞手段，仍保留空中状态和逐攻击对空能力。不对空的攻击不能伤害空中目标，但仍先参与互攻比较。打落命中后经免控判定成功，可影响后面的不对空攻击，不追溯修改前面的结果。

## 5. 简化后的统一判定流程

### 5.1 行动、意图和投递分离

- 行动身份记录本回合选择了什么，用于火炬和均衡之刃等判断；被压制不抹去行动身份。
- 攻击意图记录原本指向谁及点数，用于互攻；不能因为先结算、被免疫或防住而从反击比较中删除。
- 实际投递按优先级处理，分别得到失效、免疫、防住、命中盾或生命伤害等结果。结果只影响对应目标，不自动删除整次群攻。

法术没有攻击点数，不与攻击比较。各组件共用对应处理器，当前不需要禁法状态、控制图或反弹重投递。

### 5.2 回合状态机

| 阶段 | 执行内容 | 完成条件 |
| --- | --- | --- |
| R0 快照与校验 | 固定存活者和座位；验证每名存活者恰好一个行动、资源、材料、目标、方向、闪避限制。停用招式拒绝。 | 所有行动合法；否则本轮不提交改变。 |
| R1 激活 | 各行动按稳定座位展开；本行动激活时只支付一次成本，立即获得基础收益、新盾/生产器、固有刚性防护并建立持续发生器。 | 所有激活完成；没有全场独立的预扣费用步骤。 |
| R2 独立法术 | 按座位、行动内效果序号处理治疗、祝福、持续防御与小电。小电命中时检查免控，成功后立刻选择并移除一件可移除实例。 | 所有法术完成；选择已作出。 |
| R3 攻击准备 | 由新行动和有效持续发生器生成意图、目标、批次依赖；确定互攻关系和稳定排序键。 | 准备好第一批可执行投递。 |
| R4 投递 | 每次按第 5.5 节处理；有承伤盾选择则即时暂停；命中回调立即执行，释放后继批次。 | 所有批次完成。 |
| R5 祝福分配 | 对实际生命伤害事件分别选择非负整数减伤。 | 满足可用资源和每次最终伤害严格大于 0。 |
| R6 判死 | 应用有效治疗和最终伤害，最终生命≤0者死亡。 | 存活集合确定。 |
| R7 持有量整理 | 判死后，存活者将全部容量/数量超限整理到合法。 | 所有相关上限满足。 |
| R8 结束 | 判最后存活者胜利/全灭平局；否则推进回合并清理到期状态。 | 本回合只提交一次。 |

新盾先存在，小电实际移除后才失去能力；不得假定它将来可能被选中而提前删除。攻击中的选盾和 R7 超限弃盾是两种选择。普通承伤即时选择仍采用 D04。当前独立法术按稳定座位执行即可，不建没有实际禁用边的图。

### 5.3 成本、持续与收益

合法性按 R0 库存和材料检查。R1 以行动为单位支付并激活，保持材料/资源不会重复消耗；后续伤害被压制、防住或免疫也不退费。基础动作没有成本，新取得资源立即可用于后续机制；每人仍只有一个新行动。

凤鸣祝福在 R2 获得，可以当回合在 R5 花费。火轮命中在 R4 立即获得 Y，不等待回合末，不触发生产器。持续攻击初次只建立发生器，R3 统一每实例每回合生成一次，不能同时额外产生一次即时攻击。

### 5.4 批次排序与回旋镖剩余问题

稳定优先键为 `点数降序、座位升序、同一来源发出次序升序、稳定编号升序`。特殊互攻克制不改变排序点数。

普通火轮、镰刀、万箭采用连续批次：拿到执行权后按段序完成，万箭先第一轮全部目标再第二轮，不插入别人的同点数批次。每段分别比较互攻、消耗盾、触发收益。同段群体目标按座位处理。

回旋镖**已确认**是各自点数不同的单体投递。仍采用 D02 暂定：保留路径依赖，第一名完成后第二名才进入优先队列，新的可执行单体再与其他批次竞争。不能把“单体标签已确定”误作“调度顺序已确定”；若把全路径全部先入队，后面的高点数会先打，这一点留作 Q02。

方向和第 k 位可在 R3 根据固定存活座位预先确定，因此互攻能够读到尚未执行的回旋镖后继意图。被压制或防住仍算经过，不中断路径，每经过一人点数继续增加；单体标签在命中前确定，虚无闪直接匹配它，不为回旋镖另写防御例外。

### 5.5 一份攻击的处理链

`到达原排序位置 → 互攻/特殊克制 → 对空 → 免疫 → 基础防法 → 命中 → 持有盾或生命伤害 → 命中后效果`

1. 按 D03，对每份甲→乙意图，寻找乙→甲的反向意图；存在能压制或等点抵消它的一份则该投递对乙无效。刀的保底和 ber 特殊克制覆盖普通关系。没有反向意图则不互攻。
2. 防住、免疫、伤害已结算都不删除用于互攻的原始意图。多份反向意图的聚合暂定仍见 Q03，不再涉及已删除的物理抵消机制。
3. 不对空时不能伤害空中目标。免疫按等级、范围和可用持有盾条件判定；明确被无视/穿透的盾能否提供免疫采用 D04。
4. 基础防法按字母匹配，免疫先于基础防法；火轮 S 仅挡第一段。二者都不消耗普通承伤盾，不记命中。
5. 通过以上检查才命中；真伤跳过普通挡伤，其他伤害由最低位置可承伤盾逐次选择处理，没有能挡的盾才记生命伤害。
6. 打掉承伤盾也算命中。火轮命中收益立即加给使用者；打落是命中后有害控制，另检查免控。无须检查当前不存在的禁法或反弹。
7. 记录完整结果及原因，后续投递读取更新后的盾和状态；不在中途判死。

### 5.6 伤害账本和回合末

每次实际生命伤害独立记录来源、目标、属性/等级、是否真伤、原伤害、祝福用量和最终伤害。盾完全抵挡的命中不产生可用祝福减伤的生命伤害事件。

治疗采用 D07：R2 成功时先受上限截顶，之后承受 R4/R5 的最终伤害。5 血治疗 1 且受伤 2 暂定剩 3，见 Q07。所有效果和祝福分配完成才判死，血量中间可为负也不提前删除玩家的本回合攻击。

D08 暂定只允许修正超限所必要的弃置，且在判死后只整理存活者。容量整理不回溯改变本回合已经完成的挡伤或免疫，也不能复活玩家。

## 6. 互攻与特殊克制

若双方攻击指向彼此，比较对应点数，高者压制低者，等点双方对应投递抵消；群攻、溅射、持续及回旋镖单体覆盖彼此也算互攻。结果只对该对手失效，不全局删除其他目标伤害。多段均使用整招完整点数，独立逐段比较。

| 关系 | 已确认规则 |
| --- | --- |
| ber 对刀 | 互攻时 ber 克刀，刀不能用保底绕过 ber。 |
| 刀保底 | 普通低点或等点时仍进入后续判定；仍受防法、免伤、免疫影响，普通持有盾不能挡真伤。 |
| 刀点刀 | 互攻中克制成本含 B 的攻击，被其余攻击克制；两把刀点刀互相抵消。名义点数 7.5 用于排序。 |

## 7. 持有盾、生产器与雷达

### 7.1 盾的共同规则

- 盾是持续持有的实例，不是基础资源 F/Y，也不等于当回合选 F/Y 的防御。
- 能正常挡下伤害的盾，以**一次伤害事件**为单位抵挡。伤害再高也不溢出；火轮两次命中需要两次抵挡。
- 普通挡伤不能阻止控制；攻击打到盾上仍算命中，因此可以触发命中附带法术。真伤不能靠挡伤的盾抵挡，但相关免疫仍有效。
- 盾有独立的等级、位置和盾位：等级决定穿透/无视关系，位置决定承伤优先级，盾位决定持有容量。三者不能混用。
- 位置数越小越先承受攻击。同位置由玩家逐次选择，不要求提前给出固定排序。小电移盾已明确立即选择；普通承伤选盾采用同样的事件即时选择机制（D04），不与判死后的超限弃盾混为一谈。
- 每名存活者回合整理后持有盾位总和不超过 5；同名盾至多 2 个，生产器同名至多 1 个；四种元素盾合计至多 2 个；四种生产器合计至多 2 个。死亡者在 D08 中不再要求作无后续用途的弃置选择。
- 允许本回合暂时超限，回合末通过弃置恢复限制；不能在平时任意主动丢盾。回合末在死亡判定之后满足全部上限；拟定只允许为修正超限而作必要弃置，见 D08/Q08。
- 新造盾或合成盾在当回合攻击前就可使用。合成幽灵盾是一个完整行动，必须消耗两面真实泡沫盾，不能用受损幽灵盾或其他材料替代。

来源：Excel A41、F01～F12。

### 8.2 附加规则、盾交互与自身防护

**ber、刀、刀点刀。** 按第 6.2 节处理特殊互攻。刀的保底包括普通同点数抵消，但不是无条件必中。刀点刀的“无视点数”仅指特殊互攻胜负关系，不表示忽略免伤、盾；名义点数 7.5 仍用于排序，特殊胜负不改排序数值（新增 U05）。

**火炬。** 只检查目标当回合是否选择基础动作 F。持有泡沫盾、方盾生产器或成本含 F 都不会单独触发 2 伤害。

**海啸。** 穿泡沫级盾；对幽灵盾触发穿泡级攻击掉两层的特例。

**火轮。** 两段各独立判定，每段完整点数都是 4。每命中一段，使用者获得 1 Y；打掉盾或造成生命伤害都算命中，被免伤、免疫或防住不算。S 防御只挡第一段，第二段仍需检查其他防护；Y/C 防御可挡两段。生产器不放大命中所得 Y。

**万箭齐发、镰刀。** 明确保留段序。万箭先对各目标进行第一轮，再进行第二轮；不能合并为一次 1.5 伤害。镰刀也不能合并为一次 1 伤害。两段之间的盾、命中附带效果等变化要保留。

**地震。** 双目标时每名目标各承受一次 1 伤害，点数 7.5。只选一名目标时只造成一次 1 伤害，点数 15；不能重复选择同一人叠成 2 伤害。穿泡沫级、闪电级盾和雷达。

**三连踹。** 保留 BBF 成本、3.5 点、单体 2 物理伤害和 FSC 防法；不提供任何伤害反弹或其他新增防效。

**太阳拳。** 保留 BBY 成本、4 点、单体 1 法术伤害、YSC 防法、对空和穿泡沫级盾；不提供任何控制反弹或其他新增法效。

**六拳合一。** 使用者当回合获得 1 级免伤和 1 级免控。攻击无视泡沫级盾和雷达；基础动作均不能防，必须依靠“防六拳合一”或其他适用机制。适当等级的免伤有效；匹配成本的元素盾免疫也可能有效，例如海神盾可匹配成本中的 F。无视泡级与幽灵盾的关系采用 D04，并在 Q04 确认。

**回旋镖。** 可选顺时针或逆时针；第一名目标点数 3，第二名 4，以此类推。经过玩家就加点，不要求先造成伤害；被防住或压制也不终止后续路径。从所选方向邻座开始，每名目标得到独立的单体投递，虚无闪可以免疫。暂定按第 5.4 节的依赖优先队列 D02 排序；投递标签已确认，实际调度仍见 Q02。

**冲天炮、冲天钻。** 按第 10 节持续攻击规则。攻击表未列额外穿盾、自身免伤或控制。

**凤鸣九天。** 攻击穿泡沫级盾。攻击前通过独立法术获得 3 祝福值，不要求命中任何人；攻击被压制、防住或使用者最后死亡都不阻止收益。当前没有禁法机制，不再为这项收益设置禁法分支。

**凤之烈焰。** 主目标穿泡沫级盾，溅射目标不穿泡沫级盾。主目标和各溅射目标独立判定，都使用点数 9；主目标未命中不阻止溅射。相邻去重且排除使用者。烈焰盾额外免疫本招。

**凤之长星。** 穿闪电级盾；按第 10 节持续 5 回合。

**流星锤。** 穿泡沫级盾。每有一名目标以基础防法防住，使用者额外受到一次 0.5 自伤；每名目标只计一次。盾挡、免伤、空中或点数压制不计入该人数。自伤是真伤，没有攻击来源，绕过所有盾，但可以被免伤处理。法术赋予的等效基础防御按 D10 计数，见 Q10；每份自伤独立为 0.5，不能用祝福值减少。

**少林棍。** 无视闪电级盾和雷达，不对空；被无视的盾不消耗。不能因为盾具有匹配 Y 的免疫，就忽略本招明确的无视闪电级规则。

**天翻地覆。** 穿泡沫级盾。命中才打落空中目标；附带打落为控制，还要检查免控。先打落、后发生的不对空攻击可以命中；后发生的打落不能反向改变之前已经判过的攻击。当前没有起飞手段，仍保留此行为。

### 9.1 法术判定

小电的移盾是 1 级有害控制，先检查免控，成功时由受术者立即从可移除对象中选一件完整移除。没有候选则不移盾，但自身 2 级免伤仍有效。当前没有把它返回施法者或取消法效的机制。

治疗只能自己，成功恢复 1，受生命上限约束。防六拳合一免费但占唯一行动，不获得资源。新闪避效果分别建立，旧效果不合并为单个期限；同回合可同时拥有 S 和 C 的等效防法，不获得对应资源也不计入基础动作连续限制。

### 9.2 虚无闪与范围标签

本次决议已经确认：回旋镖每份都是单体，虚无闪可以免疫。此结论与当前回合是否还具有虚无闪自带 C 防法无关；在后两回合 C 已到期时，范围免疫仍可挡回旋镖。

既有补充说明还确认单体多段、单目标地震、凤之烈焰主目标可免疫，并将双目标和溅射纳入可免疫范围；普通群攻不免疫。群攻即使只覆盖一名对手也不改为单体。旧 Q06 已关闭，不能继续把回旋镖归为不免疫的群体。

免疫先于防法。回旋镖被虚无的单体范围免疫阻止时，记作免疫而不是 C 防住。流星锤仍是群攻，不被这项单体范围免疫阻止；若目标当回合另有等效 C 防法，则可由 C 防住，是否计入自伤人数仍按 D10/Q10。

## 10. 持续攻击与路径单体

### 10.1 持续攻击

施放回合 t，持续 N 回合包含 t，作用于 t 至 t+N−1；仅付一次成本，锁定目标，之后不能更换。

| 招式 | N | 每回合攻击 | 固定点数 |
| --- | ---: | --- | ---: |
| 冲天炮 | 3 | 对原目标 1 物理伤害 | 5.3 |
| 冲天钻 | 4 | 对原目标 0.5 物理伤害 | 4.3 |
| 凤之长星 | 5 | 对原目标 1 法术伤害，穿闪电级盾 | 9 |

每人仍可正常选择一个新行动，旧持续攻击与新行动一起结算。重复施放建立不同实例。某次被压制、防住或免疫不自动删除未来回合效果。

来源死亡后仍保留发生器；目标死亡后如何处理采用 D09：来源死而目标活仍攻击，目标死则空转至到期、不生成互攻意图，不自动更换目标；整局结束不再生成下一回合。此项仍见 Q09。

### 10.2 回旋镖

只选择方向，不另选首目标。从方向邻座开始，第一人点数 3，第二人 4，第三人 5，依次增加，每人一份伤害 1 的物理单体攻击，对空，YSC 可防，虚无闪的单体范围免疫可防。

被防住、免疫、压制仍算经过，不停止后继，不重打先前玩家、不重复攻击自己。伤害不会因为前人防住而加大。所有目标路径在回合开始存活集合上确定；方向仅影响每人取得的点数和路径先后，不改变自身单体标签。路径与其他攻击的穿插暂用 D02，见 Q02。

## 13. 实现契约与尚待确认的统一约定

### 13.1 数值、状态和定义

点数使用十分之一整数单位：B=10、Z=8、F=15、Y=20、S=25、C=35、祝福=45；生命及伤害当前可用半点整数单位。两套单位不要混用，互攻不用浮点误差容限。

玩家、行动、法术实例、持续实例、盾实例、意图、批次、投递及选择均有稳定编号。一次行动只付一次成本，一次命中只触发一次对应回调。R0 非法输入不提交改变；选择暂停后恢复不重付、不重发收益、不重建同回合投递。

招式定义由成本与目标模式、固有组件、独立法术、攻击模板、互攻关系谓词、防法/范围/盾交互及命中回调组成。只保留当前实际使用的组件，不要求实现未来禁用机制。三连踹和太阳拳现在可以直接用普通攻击模板，不需要额外反应器。

### 13.2 选择与输出

判定输入为对局快照、每名存活者的一个新行动、已经确认的选择。输出为“不合法”“需要选择”或“回合完成”。需要选择时保存阶段、游标、已生效状态、事件和当前候选；恢复只继续该事件。

选择包括小电移盾、最低可承伤位置中的选盾、祝福分配及判死后的必要弃置。没有候选则直接继续，唯一候选可直接确定。不引入联网、限时或自动代选政策。

日志区分互攻压制、特殊克制、免疫、防住、命中、盾挡、穿透、无视、实际伤害、收益、治疗截顶、控制被免控、死亡和弃置。旧禁法/反弹/抵消事件不得出现在本版结果中。

### 13.3 投递标签与数据约束

一次投递至少携带 `投递编号、原行动/持续实例编号、使用者、目标、原始意图编号、点数、物理/法术属性、伤害及等级、范围标签、段号、对空、防法、盾交互规则、命中回调`。范围标签描述规则上的攻击形态，不是当前对象数。

| 模板 | 每份投递的范围标签 | 目标展开规则 |
| --- | --- | --- |
| 普通单体、持续单体 | 单体 | 原指定目标。 |
| 回旋镖 | 单体 | 方向路径上每名目标一份，点数按路径序号预计算。 |
| 地震单目标/双目标 | 单体/双目标 | 一名或两名不同目标，不重复选人。 |
| 普通群攻、多轮群攻 | 群体 | 存活者中排除使用者；人数减少不改标签。 |
| 凤之烈焰 | 主目标为单体，邻居为溅射 | 去重、排除使用者，主/次目标独立判定。 |

虚无闪匹配单体、双目标和溅射标签，回旋镖自然进入单体分支。每名目标的实际命中都独立，但普通群攻不能因拆成逐人投递而错误取得单体身份。

范围标签、攻击属性、等级和点数分别存储；“法术攻击”不自动变成控制，“单体”不自动表示手选目标，“真伤”也不自动无视免伤。过期实例不再生成新投递，伤害被压制不删除原始意图。

### 13.4 盾的统一路由（拟定约定 D04）

本节补足现有资料未完全闭合的穿透行为，供 Q04 确认。它是一套通用算法，不按每个攻击名字另写盾逻辑。

1. 先计算本攻击对每件盾的交互类型：普通、无视、穿透或幽灵层穿透。无视的盾不提供本次免疫，也不进入本次承伤候选；穿透的盾不提供本次匹配免疫，但仍保留被摧毁的候选身份。
2. 尚能参与免疫的元素盾/雷达，任意一个匹配则整次投递免疫，所有盾都不消耗。免伤或基础防法已经阻止的事件也不进入路由。
3. 真伤直接记生命伤害，所有普通承伤盾保留；这不取消第 2 步仍适用的免疫。
4. 普通伤害从当前最低位置的可交互盾中由玩家选一件。无候选则全额记录伤害。
5. 普通交互：普通单层盾消失并完全挡住本次；幽灵盾掉一层并完全挡住本次，即使掉至 0 也不溢出。
6. 穿透单层盾：盾消失，本次伤害未被阻挡，继续第 4 步。穿泡级遇幽灵盾：扣 `min(2,剩余层数)`，若仍有层则挡住本次；若已无层则继续第 4 步。沿途可能连续摧毁多件盾，最后仍无能挡的盾才扣血。
7. 无视泡级暂定包含幽灵盾的所有泡沫层；穿泡级仍使用上一项专门的两层扣除。这用类别匹配和每层穿透参数表达，不要求把所有盾类别排成全序。
8. 每次状态变化后重读当前实例列表；一份攻击最多消耗当前确实存在的有限盾实例，不会选到同一面已经摧毁的盾。命中只记一次，不因为穿过两面盾就重复发放火轮收益。

穿透/无视被列出的类别优先于该类别自身免疫，是为避免“地震明写穿闪级却永远先被闪电盾匹配 S 免疫”而采用的 D04。普通免伤等级和不在该类别内的其他盾免疫依旧有效。

### 13.6 持续实例与回合边界的精确定义

施放回合为 t、持续 N 回合的实例记录 `start=t, end=t+N−1`，仅当 `start≤当前回合≤end` 时有效。R8 准备进入下一回合时删除已到期实例；当前回合已经参与判定的效果不会因维护期限被追溯撤销。

新施放持续攻击只建立一份发生器，R3 统一从所有有效发生器中各生成一次当回合投递；不能又生成一次即时攻击，造成首回合打两次。每个实例记最后生成投递的回合，暂停恢复时同回合不再生成第二份。重复施放是不同编号的实例，不能误去重合并。

幽灵闪保留 t 和 t+1 的 C 防法；连环闪保留 t 至 t+2 的 S 防法。虚无闪拆成“仅 t 的 C 防法”和“t 至 t+2 的范围免疫”两份组件，共享原行动编号但各有期限；不能让当回合 C 防法错误持续三回合。刚性回合防护在回合结束后清空。基础动作的最近历史不清空，用于下一回合检查连续限制。

D09 中死亡来源保留稳定身份及尚未到期的发生器。它没有下一回合的新行动，也不因此给其他攻击凭空增加能指定死者的合法目标；其旧发生器对活目标仍正常投递。目标死亡的持续实例空转但继续经过回合计数，到期正常删除。局终直接停止回合推进，新局全部重置为第 2 节初始状态。

### 13.7 实现验收

1. 当前白名单为 32 个攻击、11 种持有物、8 个法术和 6 个基础动作；不以原表所有行自动启用动作。
2. 同一快照、座位、方向、行动和选择序列产生相同状态及日志，输入数组排列不影响结果；支持在选择处暂停并恢复。
3. 每次成本、每份持续攻击、每段命中收益均恰好处理一次，无负资源、重复溅射、重复伤害或提前判死。
4. 原始意图、实际范围标签与执行批次分开；回旋镖多目标路径不污染其单体标签，群攻只命中一人不被误转为单体。
5. 第 11 节的 37 个判例能按已确认规则或对应明确标记的暂定约定推导；旧机制用例不再执行。
6. 下面未确认的口径采用本文确定的默认行为，不由实现者在不同分支临时猜测；用户答复后只替换对应策略与受影响判例。

## 14. 简化后仍需要你确认的问题

本次决议已关闭旧 Q01 的控制图/禁法分类问题、Q03 中的物理抵消问题、Q05 的反弹问题、Q06 的回旋镖免疫问题。保留下面 8 项的旧编号便于接续；无需再次确认删除决议。

1. **Q02：回旋镖是否仍保留路径先后？** 暂定邻座 3 点投递先完成，第二人的 4 点才入队；其他攻击可在各跳之间穿插。若全部单体同时入队按点数降序，就会后面的高点数先打。现在明确了单体身份，但这两种排序尚未定案。
2. **Q03：多份反向攻击如何压制？** 暂定任意一份反向意图足以压制当前段，该段便失效；已执行、被防住或免疫的意图仍有点数压制。是否同意这一聚合规则？不再涉及已删除的抵消机制。
3. **Q04：承伤与穿盾是否采用 D04？** 命中时立即选盾；穿掉后继续打后盾或生命；三层幽灵被穿泡级打后剩一层并挡住，两层以下则穿尽后继续；无视泡级也无视幽灵层；穿/无视优先于该类别盾的免疫。哪些需要修改？
4. **Q07：满血治疗的上限何时截取？** 暂定 5 血治疗 1 后再受伤 2，最后 3 血；不是净变化得到 4。
5. **Q08：超限是否只允许必要弃置？** 暂定判死后存活者整理，弃置集合去掉任何一项都会重新超限，不能顺便多扔无关装备。
6. **Q09：持续攻击在死亡后如何处理？** 暂定来源死而目标活仍攻击，目标死则空转到期且不再参加互攻，整局结束不再结算后续回合。
7. **Q10：等效闪避是否计入流星锤的防住人数？** 暂定法术提供的等效 S/C 防法也计入；若先被免伤等更早阶段阻止则不算防法防住。流星锤的群攻不会被虚无的单体范围免疫阻止；实际基础动作历史仍分开记录。
8. **Q11：小电能否选择自己？** 暂定可选任意存活者，以付出 CC 的代价自拆一件可移除装备；免费主动丢盾仍不允许。
